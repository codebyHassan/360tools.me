Frequently Asked Questions

Everything You Need to Know About Markdown Previewing & Exporting

Detailed answers to common questions about resolutions, PDF layouts, math equations, and formatting shortcuts.

How does the Markdown to Full PNG Image export handle long documents?

When you click "Export Image (PNG)", our tool clones the entire rendered markdown document into a virtual off-screen canvas at a crisp 2x retina scale. It calculates the exact scroll height, rendering all headings, tables, blockquotes, and code blocks continuously without any scrollbars, viewport cutoffs, or blurry artifacts.

How can I ensure code blocks look beautiful in my exported PDF?

Our PDF exporter utilizes dedicated print style rules that wrap code blocks, preserve font ligatures from JetBrains Mono, and prevent awkward page breaks right in the middle of code functions. Choose from our standard A4 or US Letter layouts for instant professional outputs.

What mathematical equation syntax does KaTeX support?

KaTeX supports nearly all standard LaTeX mathematical commands, including superscripts/subscripts, fractions (\frac{a}{b}), integrals (\int), summations (\sum), square roots (\sqrt{x}), Greek letters (\alpha, \beta, \theta), matrices, and piecewise functions.

Can I customize preview themes for dark mode presentations?

Yes. Use the Theme dropdown in the top toolbar to switch between GitHub Light, GitHub Dark, Notion Clean, Dracula Studio, and Warm Sepia. When you export an image or PDF, the visual theme styling is automatically preserved in your download.

Are keyboard shortcuts supported in the Markdown editor?

Yes! You can use standard editor hotkeys: Ctrl+B or Cmd+B for bold, Ctrl+I for italics, Ctrl+K for hyperlinks, and Tab for clean two-space indentation.
