Frequently Asked Questions

Why should I minify code if my web server uses Gzip compression?

Minification and Gzip compression complement each other. Minification strips redundant syntax tokens before Gzip runs its LZ77 algorithm, resulting in even smaller network payloads.

Will minification rename my JavaScript functions or variables?

This lightweight minifier removes whitespace and comments without mangling or obfuscating variable names, making it safe for production deployments without source maps.

Can I use this tool offline?

Yes. Once the web application is loaded in your browser, the minification engine runs locally even without an active internet connection.
