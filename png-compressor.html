Lossless vs. Lossy PNG Compression

PNG files use lossless DEFLATE compression. Because PNG is designed for pixel-perfect reproduction, shrinking a PNG losslessly only removes unnecessary ancillary chunks (such as creation timestamps and color profiles). To achieve massive 70%+ file size reductions for web performance, converting transparent PNGs to transparent WebP format provides the best of both worlds: 100% alpha transparency with cutting-edge predictive compression.
